## 4. Godot Editor Panels

### A. 3D Viewport

**Purpose:** Main 3D workspace.

ELI5 explanation:

Imagine an empty piece of land where we build a house.

The 3D Viewport is where we will create the TWELVEND world.

Planned uses:
- Build the ancestral house.
- Create rooms.
- Add trees and vegetation.
- Create the pond and backwater.
- Position objects and lights.

### B. Scene Panel

**Purpose:** Displays the nodes belonging to the currently open scene.

ELI5 explanation:

Imagine a list of objects inside a room.

The Scene panel shows the building blocks used in that scene.

Examples:
- Floor
- Walls
- Doors
- Lights
- Furniture

### C. Inspector Panel

**Purpose:** Displays properties of the selected node or resource.

ELI5 explanation:

Imagine selecting a chair and changing its size or colour.

The Inspector is where we change an object's settings.

Examples:
- Position
- Rotation
- Scale
- Material
- Other properties

### D. FileSystem Panel

**Purpose:** Displays project folders and files.

ELI5 explanation:

Imagine a cupboard containing all the things needed to build a game.

The FileSystem shows:
- Scenes
- Scripts
- Images
- Audio
- Models
- Documentation

### E. Bottom Panel

**Purpose:** Displays useful development information.

Examples:
- Output
- Debugger
- Errors
- Warnings

These tools will help us identify and fix problems.

## 5. Important Editor Buttons

| Button | Purpose |
|---|---|
| Play Project | Runs the configured main scene |
| Play Current Scene | Runs the currently open scene |
| Stop | Stops the running game |
| Save | Saves the current work |
| Script | Opens the scripting workspace |

Note:

The game does not have a completed playable main scene yet.
Therefore, Play Project may not start a playable game at this stage.
